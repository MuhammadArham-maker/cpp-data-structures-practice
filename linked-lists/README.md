# Linked Lists

`Linked_List.cpp` contains menu-driven implementations and operations for singly linked lists, doubly linked lists and circular linked lists.

Compile from the repository root:

```bash
g++ -std=c++17 linked-lists/Linked_List.cpp -o linked-list-suite
```
