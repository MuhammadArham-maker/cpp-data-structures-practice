# Arrays

`Array.cpp` is a menu-driven collection of array exercises, including finding extrema, reversing and rotating arrays, handling duplicates, finding a missing value, merging sorted arrays, and finding a pair with a target sum.

Compile from the repository root:

```bash
g++ -std=c++17 arrays/Array.cpp -o array-suite
```
