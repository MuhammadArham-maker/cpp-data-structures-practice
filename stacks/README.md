# Stacks

`Stack.cpp` includes an array-based stack, a linked-list-based stack, string reversal, balanced-bracket checking, infix-to-postfix conversion and postfix-expression evaluation.

Compile from the repository root:

```bash
g++ -std=c++17 stacks/Stack.cpp -o stack-suite
```
