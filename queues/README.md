# Queues

`Queue.cpp` includes a circular array queue, a linked-list queue, stack/queue conversion exercises, queue reversal using a stack and a deque implementation.

Compile from the repository root:

```bash
g++ -std=c++17 queues/Queue.cpp -o queue-suite
```
